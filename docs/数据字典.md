# 数据字典

数据库：SQLite，默认 `data/his_intel.db`。表结构定义见 [app/db.py](file:///d:/D_file/jgq_ys/newjob/tianyancha/app/db.py#L14-L165)。

## 1. 实体关系

```
regions(市州) 1──n hospitals(医院) 1──n announcements(公告) 1──n awards(中标结果)
                                                    └──n attachments(附件)
announcements ── hospital_id ──> hospitals.id
crawl_tasks 1──n crawl_logs
users / audit_logs / change_history / source_health 为运维与审计表
```

## 2. 表说明

### regions 市州

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| code | TEXT PK | 行政区划代码，如 430100 |
| name | TEXT | 全称，如「湘西土家族苗族自治州」 |
| short | TEXT | 简称，如「湘西」，用于页面与匹配 |

初始化时种入湖南 14 个市州，不随采集变化。

### hospitals 采购单位/医院

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| name | TEXT | 原始医院名（首次发现的写法） |
| norm_name | TEXT UNIQUE | 归一名称，去重键；去括号、去「本级」、后缀折叠（「…妇幼保健院医院」→「…妇幼保健院」） |
| city_code | TEXT | 关联 regions.code；无法判定为 NULL |
| level | TEXT | 医院等级，名录导入时填写 |
| ownership | TEXT | 默认「公立」 |
| aliases | TEXT(JSON) | 别名数组，预留人工合并 |
| source / source_url | TEXT | 首次发现来源与公告链接 |
| first_seen_at | TEXT | 首次发现时间 |

### brands HIS 厂家品牌

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| name | TEXT UNIQUE | 品牌名，如「东华医为」「卫宁健康」 |
| aliases | TEXT(JSON) | 别名 |
| category | TEXT | 默认 HIS |
| is_unknown | INTEGER | 是否「未知/未识别」占位 |

来源 `config/brands.json`，共 20 个品牌；可人工增改。

### supplier_brand_rules 供应商→品牌规则

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| pattern | TEXT | 匹配串（供应商名或关键词） |
| brand_name | TEXT | 命中后归入的品牌 |
| match_type | TEXT | `contains`（默认）/ `equals` |
| priority | INTEGER | 优先级，数值越大越优先 |
| note | TEXT | 备注 |

来源 `config/supplier_brand_rules.csv`；支持人工维护。命中供应商名置信度 0.9。

### announcements 招标/中标公告

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| source_site | TEXT | 采集器 ID，如 `hunan_gov_search` |
| source_name | TEXT | 来源站点名 |
| url | TEXT UNIQUE | 公告原文链接，**去重键之一** |
| notice_id | TEXT | 站点原始公告编号（可得时） |
| title | TEXT | 招标项目名称 |
| notice_type | TEXT | 公告类型（中标/成交/采购等） |
| publish_date | TEXT | 发布日期 `YYYY-MM-DD`，中标日期口径 |
| purchaser_raw | TEXT | 抽取的采购单位原文 |
| purchaser_norm | TEXT | 归一后的采购单位 |
| hospital_id | INTEGER | 关联 hospitals.id |
| city_code | TEXT | 关联 regions.code |
| budget_yuan | REAL | 预算/中标金额（元）；缺失为 NULL |
| content_hash | TEXT | 去空白全文 SHA256，内容变更检测 |
| raw_text | TEXT | 正文前 20000 字，用于复核与检索 |
| matched_keywords | TEXT(JSON) | 命中的 HIS 关键词 |
| relevance | REAL | HIS 相关度得分（标题 3 / 正文 1，阈值 3） |
| fetch_status | TEXT | `ok` / `detail_unreachable` |
| is_void | INTEGER | 是否流标/废标/终止，1 排除 |
| first_seen_at / last_seen_at | TEXT | 首次/最近采集时间 |

索引：hospital_id、city_code、publish_date、content_hash。

**去重键**：`url` 唯一；同一 URL 内容哈希变化时更新并写 `change_history`。跨站点同一公告目前按 URL 视为不同记录，后续可加「公告编号 + 标题相似度」兜底。

### awards 中标结果

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| announcement_id | INTEGER | 关联 announcements.id |
| package_no | TEXT | 包件号，单包为 "1" |
| supplier_raw | TEXT | 中标供应商原文（只取首个中标供应商） |
| supplier_norm | TEXT | 供应商名归一 |
| brand_name | TEXT | HIS 品牌；无法识别为「未识别」 |
| brand_confidence | REAL | 0.9 供应商名命中 / 0.45 正文命中 / 0 未识别 |
| amount_yuan | REAL | 中标金额（元） |
| amount_raw | TEXT | 原始金额文本（含中文大写） |
| award_date | TEXT | 中标日期 |
| is_winner | INTEGER | 默认 1 |

**注意**：一条公告只记录实际中标供应商，代理机构、投标人、联合体成员不作为中标单位；抽取不到时保留 `supplier_raw=''` 的「未识别」行，保证公告仍可统计。

### attachments 附件

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| announcement_id | INTEGER | 关联公告 |
| name | TEXT | 附件显示名 |
| url | TEXT | 附件直链 |
| local_path | TEXT | 本地相对路径 `data/attachments/{ann_id}/{att_id}.ext` |
| sha256 | TEXT | 文件哈希 |
| size | INTEGER | 字节数 |
| status | TEXT | `unverified` / `ok` / `download_failed` |
| checked_at | TEXT | 最近检测时间 |

单公告最多解析 6 个、下载前 3 个；下载失败不重试即标记，不伪造文件。

### crawl_tasks 采集任务

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增 |
| source | TEXT | 参与的源，`+` 连接 |
| params | TEXT(JSON) | 关键词、since 等 |
| status | TEXT | `running` / `done` / `stopped` / `failed` |
| started_at / finished_at | TEXT | 起止时间 |
| pages / items / inserted / updated | INTEGER | 页数、候选数、新增、更新 |
| error | TEXT | 失败原因 |

### crawl_logs 采集日志

`task_id`、`ts`、`level`（info/warning/error）、`message`。页面可查看单任务日志。

### change_history 变更历史

`entity`（如 announcement）、`entity_id`、`field`（如 content_hash）、`old_value`、`new_value`、`changed_at`、`actor`（collector/system/用户名）。用于内容变更与人工维护留痕。

### users 用户

`username` UNIQUE、`password_hash`（werkzeug PBKDF2）、`role`（admin/analyst/viewer）、`created_at`。

### audit_logs 操作审计

`username`、`action`（login/collect/export/edit 等）、`detail`、`ip`、`ts`。

### source_health 数据源健康

`source` UNIQUE、`last_check`、`status`（available/unreachable/error/blocked）、`http_code`、`note`。

## 3. 取数口径

### 每家医院最近 2 次

```sql
WITH ranked AS (
  SELECT a.id, a.hospital_id,
         ROW_NUMBER() OVER (PARTITION BY a.hospital_id
                            ORDER BY COALESCE(a.publish_date,'') DESC, a.id DESC) AS rn
  FROM announcements a
  WHERE a.hospital_id IS NOT NULL AND a.is_void = 0
)
SELECT * FROM ranked WHERE rn <= 2;
```

- 排序：中标/发布日期倒序；同一天按入库 id 倒序（后入库视为更新）。
- 同一天多包：按公告计 1 次，金额取该公告最大包件金额，中标单位去重合并。
- 流标/废标：`is_void=1` 直接排除，不占名额。
- 品牌筛选：命中所选品牌即保留该公告。

### HIS 相关度

`his_relevance(title, full_text)`：标题命中关键词 +3，正文命中 +1，`score >= 3` 入库。关键词表见 `config/his_keywords.txt`。

### 金额解析

`extract_amount` 支持 `123.45万元`、`1,234,567.89元`、中文大写（壹佰贰拾万元整）等，统一换算为元。无金额返回 `(None, "")`。

### 品牌置信度

| 置信度 | 依据 | 页面标识 |
| --- | --- | --- |
| 0.9 | 供应商名称命中规则表 | 正常显示品牌 |
| 0.45 | 公告正文命中品牌/别名 | 「品牌 · 待核」 |
| 0 | 无命中 | 「未识别」 |

禁止将未命中记录强行归入某品牌。
